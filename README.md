# Train Collision Avoidance System (TCAS)

A C++23 Real-Time Train Collision Avoidance System.

## Directory Structure
- `include/`: Header files (`common/Types.hpp`, etc.)
- `src/`: Source code (`main.cpp`)
- `tests/`: Unit tests (`test_main.cpp`)
- `data/`: Network and simulation JSON configurations
- `logs/`: Runtime logs
- `docs/`: Architecture and design documentation
